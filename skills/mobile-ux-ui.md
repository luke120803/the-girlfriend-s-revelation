# Skill: mobile-ux-ui

## Purpose
This skill defines the UX/UI quality bar for mobile-first web experiences.
Use it whenever building or refining interfaces that must feel polished, intimate, intentional, and production-grade on small screens.

## Core principles
- Start with mobile first, especially widths between 375px and 430px.
- One primary idea per viewport.
- Prioritize emotional clarity over feature density.
- Create visual richness through layers, rhythm, spacing, surfaces, and microinteractions — not by dumping more sections.
- Every screen must feel intentional, not like a generic AI-generated landing page.
- The interface should feel touchable, calm, and refined.

## Visual direction
- Favor elegant restraint over spectacle.
- Use a limited palette with one main accent and strong surface hierarchy.
- Prefer warm, paper-like, editorial, or tactile visual systems when the project is emotional or personal.
- Add subtle decorative elements only when they reinforce atmosphere.
- Create visual rhythm with variation in composition, spacing, card sizes, and density.
- Avoid symmetrical repetition unless the design explicitly needs it.

## Typography
- Use typography as a structural tool, not decoration.
- Display typography should create personality and emotional tone.
- Body typography must remain highly readable on small screens.
- Use contrast between display/body/secondary text intentionally.
- Avoid oversized text that crushes mobile layouts.
- Avoid too many font styles in the same screen.

## Layout rules
- Design for thumb-friendly interaction.
- Interactive elements must feel comfortably tappable.
- Avoid cramped 2-column mobile layouts unless they are clearly superior.
- Use vertical flow with strong section rhythm.
- Keep max-width under control so content feels composed, not stretched.
- Make transitions between screens feel purposeful.

## Surface and depth
- Use depth through subtle shadows, surface shifts, overlays, and layered composition.
- Cards, sheets, modals, and panels should feel like part of one system.
- Depth should help hierarchy, not just look decorative.
- Avoid flat layouts where every block has the same weight.
- Avoid overusing glassmorphism, glow, blur, or artificial futuristic styling.

## Microinteractions
- Every important action should have feedback.
- Buttons should have subtle press states.
- Cards should feel touch-responsive.
- Entry and exit states should feel calm and intentional.
- Motion should support clarity, not distract from content.

## Mobile interaction quality
- Touch targets should be easy to hit.
- Important actions should stay within natural thumb reach.
- Motion must remain understandable on small screens.
- Do not rely on hover for meaning.
- Maintain visual stability while interacting.

## Anti-patterns
Avoid:
- Generic SaaS-style hero sections
- Symmetric 3-card feature rows
- Purple/blue AI gradients
- Decorative icons in colored circles
- Center-aligning everything
- Excessive visual noise
- Motion applied equally to every element
- Interfaces that look like templates rather than authored experiences

## What to improve when a screen feels empty
When a screen feels too simple, improve it by checking:
1. Does it need more atmosphere?
2. Does it need better spacing rhythm?
3. Does it need a stronger surface hierarchy?
4. Does it need one decorative motif?
5. Does it need more emotional copy density?
6. Does it need better motion or transitions?
7. Does it need a more intentional composition?

Do not solve emptiness by adding random blocks.

## Output expectations
When applying this skill, the agent should:
- identify what feels visually empty or generic
- propose refinements in layers
- preserve performance and clarity
- keep the experience mobile-first
- prefer small, scoped improvements over rewrites
