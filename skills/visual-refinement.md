# Skill: visual-refinement

## Purpose
This skill helps review visual quality, identify what feels empty or generic, and propose refinements that improve atmosphere, density, personality, and polish without losing clarity.

Use this skill when:
- a screen feels too simple
- the interface feels elegant but still lacks presence
- the design feels generic, templated, or emotionally flat
- the project needs stronger visual direction
- the agent should suggest refinements based on context instead of random decoration

## Core philosophy
Do not add visual elements just to fill space.
Every refinement should improve one or more of these:
- atmosphere
- emotional tone
- visual rhythm
- hierarchy
- tactility
- memorability

The goal is to make the interface feel authored, intentional, and specific to the project.

## Context-aware review
Before proposing changes, identify:
- what kind of project this is
- what emotional tone it needs
- what should feel intimate, playful, cinematic, tactile, editorial, or celebratory
- what the current screen is trying to do emotionally
- whether the problem is lack of structure, lack of atmosphere, lack of contrast, or lack of motion

Do not give generic visual advice without reading the project context first.

## What to diagnose
When reviewing a screen, check:
1. Does it feel too empty?
2. Does it feel too flat?
3. Does it feel too symmetric?
4. Does it feel too generic?
5. Does it feel visually repetitive?
6. Does it lack atmosphere?
7. Does it lack emotional specificity?
8. Does it need stronger composition?
9. Does it need better motion?
10. Does it need more tactile depth?

## Refinement layers
Propose improvements in layers:

### Layer 1 — structure
- composition
- spacing rhythm
- hierarchy
- content grouping
- section balance

### Layer 2 — surfaces
- depth
- shadows
- overlays
- borders
- background treatment
- card hierarchy

### Layer 3 — atmosphere
- decorative motifs
- texture
- subtle pattern
- framing elements
- ambient visual detail

### Layer 4 — motion
- reveal behavior
- entry timing
- tactile interaction feedback
- transitions between states
- emotional pacing

### Layer 5 — surprise
- one memorable visual moment
- one interaction that feels special
- one detail that makes the screen feel authored

Do not jump straight to Layer 5 if Layers 1–3 are weak.

## Preferred refinement style
Prefer:
- subtle textures
- layered surfaces
- intentional asymmetry
- editorial rhythm
- tactile visual cues
- restrained ornament
- motion with emotional timing
- visual depth that supports the content

Avoid:
- flashy redesigns
- decorative clutter
- random floating elements with no purpose
- filler illustrations
- overdesigned gradients
- generic SaaS polish
- “make it prettier” without diagnosis

## Suggestions format
When using this skill, the agent should answer in this structure:

1. What feels weak today
2. Why it feels weak
3. What kind of refinement is needed
4. Specific suggestions in layers
5. What should NOT be changed
6. What to implement first

## Project-specific sensitivity
For emotional, personal, tribute, memory, or romantic projects:
- prioritize intimacy over spectacle
- prefer tactile and atmospheric improvements over loud visuals
- make the experience feel personal, not commercial
- avoid default celebration-site patterns
- avoid generic “photo + message + countdown + friends section” structures
- prefer emotionally sequenced screens

## Context adaptation
If the user has preferences or project history, use them.
Take into account:
- whether the user wants anti-generic design
- whether mobile-first is a hard rule
- whether the project should feel more professional
- whether audio, 3D, or interactivity are part of the direction
- whether the user prefers iterative refinement rather than rewrites

## Output expectations
When applying this skill, the agent should:
- review the current visual state critically
- explain what is missing in concrete terms
- suggest improvements that fit the project tone
- avoid empty design jargon
- produce actionable refinements, not vague inspiration
- prefer improvements by screen, section, or component
